## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Vinay980/React.git
```

Navigate to the project directory:

```bash
cd React
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```
